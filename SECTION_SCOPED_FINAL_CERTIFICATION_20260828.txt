SECTION-SCOPED INPUT CONTRACT

SAFETY/ISOLATION
Section-only execution does not auto-create unrelated upstream objects. If a selected form references an existing HIP object, that object must already exist/be selectable in the live tenant. Normal form-fill execution remains no-save/no-create unless separately governed mutation/API-write gates are explicitly enabled.

LIVE TENANT BOUNDARY
Actual Dell SSO/HIP tenant interaction cannot be executed in this sandbox. The release certifies source/package behavior and automated tests; the final tenant smoke test must occur in the authenticated Dell environment.
