# v2.1.4 Semantic Website Understanding + Multi-Evidence Action Gate

## Execution contract

AutoWebGLM remains the primary browser planner. Reviewed deterministic phase intent is resolved to one live HIP control by a fail-closed semantic gate. Evidence is fused from the exact Playwright locator, Playwright MCP accessibility search/snapshot, Chrome DevTools MCP DOM snapshot, HIP Intelligence MCP semantic ranking/critique, previously validated value-free control fingerprints, and Gemma vision only when ambiguity remains.

The selected control receives a stable `SC-...` semantic ID. The gate requires the configured confidence threshold and runner-up margin, then revalidates the fingerprint after any Angular/DDS rerender immediately before dispatch. Official Playwright MCP executes safe click/fill/select actions first; deterministic Python Playwright is the exact DDS fallback and PyAutoGUI remains last resort. Every successful action must produce a proven semantic effect before the state transition can be learned.

## Covered shared execution surfaces

- ordinary BrowserSession click/fill/search actions
- DDS single-select and owned options
- DDS multi-select exact-set actions
- checkbox, radio and boolean/toggle controls
- tab navigation
- repeatable-row `+ Add` actions with exact +1 row proof
- structural-parent/dependency exploration
- file uploads, including visually hidden `input[type=file]` controls
- pre-dispatch fingerprint drift/rebind
- Mission Trace semantic provenance
- Live GO/NO-GO semantic MCP capability gate

## MCP policy

No TypeScript MCP or second generic browser automation MCP is added. The three-purpose MCP architecture is retained: Playwright MCP = primary browser executor, Chrome DevTools MCP = independent DOM/network/console verifier, HIP Intelligence MCP = HIP-specific semantic website brain.

## Safety

Fingerprints and learned state graphs are value-free. Customer-entered field values are not persisted by the semantic learning layer. Vision cannot generate coordinates or independently authorize a click. Witness-mode mutation blocking remains unchanged.
